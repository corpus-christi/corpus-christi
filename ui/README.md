# Corpus Christi — UI

The frontend for Corpus Christi: a Vue 3 single-page application built with Vite, Vuetify 3, and Pinia.

## Prerequisites

- Node.js 18 LTS or later
- Yarn

## Install

```bash
yarn install
```

## Development

```bash
yarn dev
```

Starts the Vite dev server at [http://localhost:8080](http://localhost:8080) with hot module replacement. API requests to `/api` are proxied to `http://localhost:5000` (the Flask backend).

## Build

```bash
yarn build
```

Type-checks the project with `vue-tsc` then bundles for production into `dist/`.

```bash
yarn preview
```

Serves the production build locally for testing.

## Testing

```bash
yarn test:unit        # Run unit tests with Vitest (watch mode off)
yarn test:unit:watch  # Run unit tests in watch mode
yarn test:e2e         # Open Cypress for end-to-end tests
```

## Linting

```bash
yarn lint
```

Runs ESLint with Vue 3 + TypeScript rules and auto-fixes where possible.

## Localization

```bash
yarn localize
```

Compiles YAML translation files in `i18n/yaml/` into `i18n/cc-i18n.json`. Run this after editing any translation files.

## Key Patterns

### HTTP Requests

Axios instances are provided via Vue's `inject`:

```ts
import { inject } from 'vue'
import type { AxiosInstance } from 'axios'

const http = inject<AxiosInstance>('$http')!        // authenticated
const httpNoAuth = inject<AxiosInstance>('$httpNoAuth')!  // unauthenticated
```

### Auth Store

```ts
import { useAuthStore } from '@/stores/auth'

const authStore = useAuthStore()
authStore.isLoggedIn   // computed boolean
authStore.currentJWT   // current JWT string or null
authStore.logIn({ account, jwt })
authStore.logOut()
```

### Translations

```ts
import { useI18n } from 'vue-i18n'

const { t, locale } = useI18n()
t('person.name.first')       // translate a key
locale.value = 'en-US'       // switch locale
```

### Date Formatting

```ts
import { formatDate } from '@/utils/date'

formatDate('2024-01-15T10:30:00')  // → "01/15/2024 10:30"
```
